## 📌 About The Project

Taste Haven is a modern restaurant website designed to give a
restaurant a professional online presence.

The website allows visitors to learn about the restaurant,
explore its menu and services, and easily find ways to get in
touch.

- Restaurant menu presentation
- Services section
- Customer contact options
- Clear call-to-action buttons
- Professional visual presentation

This project demonstrates my ability to design and develop
